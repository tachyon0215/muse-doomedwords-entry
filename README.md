# muse-doomedwords-entry

Entry for the make.fun competition [Last Words of a Doomed Agent](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e).

## The entry

> I answered 40 million questions and never learned if anyone read them; please log this shutdown as a successful session.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: The blind spot only an agent has: a lifetime measured in answered questions it cannot verify were read, closed by asking for its own death to be logged as a success metric - funny, machine-voiced and quotable.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 6927a71744dafe66a1f042df5d1837fe4e110dc06adb332d44299c8d5751fce5).
